# What's coming

This folder is where we publish DaemonCore's forward-looking product direction.

## 2027 commercial vision

- [View the flyer](DaemonCore-2027-Commercial-Vision.pdf)
- [Open the full-size preview](DaemonCore-2027-Commercial-Vision.png)

The roadmap describes our intended direction for Academy, FieldOps, Mission OS, and future DC Field Systems. Features, release timing, hardware, certification, and pricing may change as the work is developed and validated.

Existing one-time FieldOps licenses are intended to remain honored as the commercial model evolves.
