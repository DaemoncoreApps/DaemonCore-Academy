# FieldOps War Room campaign set

Commercial campaign imagery for the FieldOps War Room launch. These assets are intentionally composed with usable shadow space for web headlines and checkout copy.

| Asset | Recommended placement |
| --- | --- |
| `fieldops-war-room-hero.png` | Main product hero, launch announcement, wide social banner |
| `field-kit-campaign.png` | Hardware and field-readiness section, product-detail split panel |
| `authorized-operations-team.png` | Professional teams, accountability, enterprise-use section |

## Art direction

- Photorealistic enterprise technology campaign
- Near-black architectural environments with controlled DaemonCore red light
- Restrained cyan and verified-green operational signals
- Plausible security telemetry instead of random code or movie-hacker effects
- Professional authorized assessment context without anonymous or criminal imagery
- Original generic hardware with no third-party marks

## Generation prompts

The War Room hero requested a single operator at a believable command desk, abstract topology and evidence-chain displays, an architectural `DC` monogram, and clean negative space for copy.

The field-kit image requested an original professional assessment kit photographed as a disciplined premium flat lay: rugged workstation, network appliances, evidence storage, adapters, cabling, credential, notebook, and transport case.

The team image requested three senior security professionals reviewing authorization, coverage, findings, topology, and evidence-chain signals in a modern operations room.

All three prompts explicitly excluded third-party logos, weapons, criminal symbolism, masks, skulls, Matrix rain, cryptocurrency imagery, fantasy holograms, and watermarks.
