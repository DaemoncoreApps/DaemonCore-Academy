# DaemonCore Academy 6.0.0 // Remember the operator

DaemonCore Academy 6 is the stable Windows release of Mission OS: a guided, local-first cyber training environment with evidence-led lessons, disposable Docker ranges, professional routes, and the authorization-bound FieldOps workspace.

## Mission OS

- A twelve-scenario entry diagnostic establishes a durable capability baseline.
- Six professional routes turn the catalog into deliberate role-based training.
- The Learn -> Practice -> Launch -> Prove workflow makes the next action explicit.
- Lessons distinguish worked command examples from commands intended for a live range.
- Guided first missions, direct range handoffs, and persistent next-step controls reduce setup ambiguity.
- After-action reviews evaluate evidence coverage, independence, method, and time discipline.

## Durable operator record

- Operator identity, progress, Mission OS state, settings, FieldOps records, and licensing remain outside the installation directory.
- The installer identifies an existing copy, asks before replacing it, and retains application data.
- A browser recovery mirror can restore affected earlier records when no durable desktop profile exists.
- Restart and upgrade checks exercise persistence across independent application processes.

## Practical work

- Adaptive ranges support Guided, Assisted, Blind, and Professional modes.
- Backend-owned evidence gates accept proven outcomes instead of one magic command string.
- Seven sealed Docker scenarios, enterprise cases, Web Forge, and three principal capstones provide hands-on work.
- FieldOps combines signed permits, scoped diagnostics, campaigns, sealed captures, findings, retests, reports, and bounded Chaos Engine experiments behind the FieldOps Pro entitlement.

## Upgrade

Close DaemonCore Academy before running setup. The installer asks before removing the previous program version and retains the version-independent operator record. Export important records from Settings before any material upgrade.

## Important Windows signing notice

**This installer is not Authenticode-signed. Windows may display Unknown Publisher or a Microsoft Defender SmartScreen warning.** Download only from this official GitHub release and verify `DaemonCore-Academy-Setup.exe` against `SHA256SUMS-windows.txt` before running it. Do not treat the package as a trusted signed deployment in a managed fleet.

Public code signing is planned for a follow-up release. Signing will not change the permanent Windows download URL.

## Linux

Linux remains on the separately labeled `6.0.0-beta.3` channel while cross-platform certification continues. Its AppImage and Debian package remain available from that tagged release.
