# DaemonCore Academy 6.0.2 // Bring the Deck Online

DaemonCore Academy 6.0.2 is a focused FieldOps presentation and usability release. It makes the War Room feel like the professional control surface it already is without inventing telemetry or weakening its authorization boundaries.

## War Room Refresh

- A short command-deck boot establishes FieldOps context and automatically clears before interaction. Reduced-motion preferences disable it.
- The new readiness rail reports the real protected operator, permit, validity window, and evidence-chain state.
- A contextual primary action routes the operator toward the first capture, active campaign, open findings, or evidence vault based on the current case.
- Empty FieldOps accounts now receive a visible Declare → Acquire → Prove route instead of a dead dashboard.
- Diagnostics, Campaigns, Evidence, Findings, and Chaos Engine are all first-class launch surfaces.
- Large authorized scopes clearly show when additional targets continue in the Engagement Vault.
- Layouts adapt across the supported desktop widths while preserving the larger FieldOps typography floor.

## What did not change

- FieldOps Pro remains the only commercial gate; Academy remains available without purchase.
- Existing Lemon Squeezy activations, operator records, signed permits, evidence, findings, reports, and course progress remain intact through upgrade.
- Every operation remains limited to the signed policy, exact targets, declared ports, network boundary, and testing window.
- Windows 6.0.2 remains temporarily unsigned. Evaluate it in a disposable Windows 10/11 VM and verify the published SHA-256 checksum before installation.

## Upgrade

Close DaemonCore Academy before running setup. The installer replaces the existing program files while preserving the version-independent application-data directory. Export important records from Settings before any material upgrade.

Linux remains on the separately labeled `6.0.0-beta.3` channel.
