# DaemonCore Academy 5.3.0

FieldOps can finally run the engagement, not just one target at a time.

## What landed

- Campaign Engine runs fixed evidence profiles across up to 100 explicitly authorized targets, with pause, resume, cancellation, retry, and restart recovery.
- Trust Authority binds each engagement to a protected operator identity, named approver, signed permit, declared scope, policy, and testing window.
- Every FieldOps operation produces a named, timestamped, tamper-evident receipt for the activity ledger and client deliverables.
- Deep Service Inventory captures service, version, product, CPE, HTTP, TLS, and raw sealed evidence through Nmap, Docker, or the native fallback engine.
- Identity Citadel now launches a genuine disposable Samba Active Directory realm and certifies DNS, Kerberos, GSSAPI-protected LDAP, SMB, and finding submission.
- The Windows installer keeps one application identity and install path, confirms upgrades, and retains local Academy and FieldOps data.

## Access model

Academy remains available before purchase. A valid Lemon Squeezy license unlocks FieldOps Pro. Every real-system operation still requires explicit target scope and an active signed engagement permit.

## Upgrade

Run the installer over an older version. It upgrades the existing DaemonCore Academy installation instead of creating another side-by-side copy.
