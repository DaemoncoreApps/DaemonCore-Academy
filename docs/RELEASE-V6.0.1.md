# DaemonCore Academy 6.0.1 // Enter the War Room

DaemonCore Academy 6.0.1 turns FieldOps into a focused professional operations workspace while preserving the Mission OS curriculum, sealed ranges, durable operator record, and authorization boundaries introduced in 6.0.0.

## FieldOps War Room

- The new command deck puts the active permit window, named operator, signature integrity, surface coverage, campaigns, findings, and ledger activity in one operational view.
- The authorized-surface matrix shows which exact scoped systems have produced evidence and which still need attention.
- Diagnostics, multi-target campaigns, findings, retests, reports, and Chaos Engine runs now read as one continuous engagement workflow.
- Guided empty states identify the next valid action instead of leaving operators in a decorative dashboard.
- The locked FieldOps preview now explains the complete professional workflow before purchase without paywalling the Academy.

## Professional operations retained

- Every engagement remains bound to a signed permit, protected operator identity, exact targets, declared ports, policy level, and validity window.
- Deep Service Inventory can use local Nmap or a pinned Docker image and falls back to the built-in profiler when neither is available.
- Evidence captures retain target, timing, resolved-address, digest, and source context for findings and reports.
- Campaigns coordinate Complete Assessment, Service Inventory, and Change Verification across the authorized target set.
- High-intensity resilience work remains bounded by the existing signed authorization policy and sealed Academy range controls.

## Enterprise brief

The repository now includes an editable Word brief and distribution-ready PDF for security leadership, learning teams, endpoint engineering, legal, and procurement. It presents the verified curriculum, practical environments, FieldOps governance, deployment facts, stakeholder value, and a suggested six-week enterprise pilot without claiming unshipped central administration or compliance certifications.

## Upgrade

Close DaemonCore Academy before running setup. The installer detects an existing installation, asks before replacing it, and retains the version-independent operator record, progress, FieldOps case files, settings, and license data. Export important records from Settings before any material upgrade.

## Important Windows signing notice

**This installer is not Authenticode-signed. Windows may display Unknown Publisher or a Microsoft Defender SmartScreen warning.** Download only from this official GitHub release and verify `DaemonCore-Academy-Setup.exe` against `SHA256SUMS-windows.txt` before running it. Do not treat the package as a trusted signed deployment in a managed fleet.

Public code signing remains planned for a follow-up release. Signing will not change the permanent Windows download URL.

## Linux

Linux remains on the separately labeled `6.0.0-beta.3` channel while cross-platform certification continues. Its AppImage and Debian package remain available from that tagged release.
